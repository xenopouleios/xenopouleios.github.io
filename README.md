# Ξενοπούλειο

Ανεξάρτητη, στατική ιστοσελίδα με τέσσερις ενότητες:

- Ξενοπούλειος Παιδική Βιβλιοθήκη
- Μουσείο Ξενόπουλου
- Σύλλογος Φίλων
- Δίκτυο Freinet

## Προεπισκόπηση

Ανοίξτε το `index.html` σε έναν σύγχρονο browser. Δεν απαιτούνται εγκατάσταση πακέτων, build ή κλειδιά πρόσβασης.

## Δημοσίευση

Η ιστοσελίδα δημοσιεύεται στο GitHub Pages από το workflow `.github/workflows/pages.yml` σε κάθε push στο `main`. Στις ρυθμίσεις του αποθετηρίου, στο **Settings → Pages → Source**, επιλέξτε **GitHub Actions**.

Μόνο τα `index.html`, `styles.css` και `favicon.svg` περιλαμβάνονται στη δημοσίευση. Οι σχετικές διευθύνσεις επιτρέπουν τη φιλοξενία κάτω από το `/xenopouleio/` ή σε ανεξάρτητο domain.

## Περιεχόμενο

Η πρώτη έκδοση περιλαμβάνει εισαγωγικά κείμενα και σαφείς ενδείξεις για περιεχόμενο που ετοιμάζεται. Δεν περιλαμβάνει επιβεβαιωμένα ωράρια, στοιχεία επικοινωνίας, εκδηλώσεις ή φόρμα εγγραφής. Προσθέστε τα μόνο αφού επιβεβαιωθούν από τους υπευθύνους.

Η εικονογράφηση είναι ενσωματωμένη στο HTML ως SVG. Δεν χρησιμοποιούνται εξωτερικές γραμματοσειρές, υπηρεσίες analytics ή cookies.
